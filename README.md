# PreEvac — download

Landing page and release builds for **PreEvac**, a real-time disaster alerting
app for Android.

- **Download:** [latest release](../../releases/latest)
- **Landing page:** https://erick-mureruswa.github.io/preevac-releases/

Disaster data comes from USGS, GDACS, NASA FIRMS and national weather agencies.
PreEvac complements official emergency warning systems; always follow
instructions from local authorities.

This repository holds the published app and its download page only. The source
lives in a separate private repository.
